# Photo Ctrl

Photograph your tool boxes, stacks and drawers, and send the photos to your own private GitHub repo. Your own Claude, with the WOODWERD photo skill in [`skill/`](skill/), reads them and writes proposals that [Tool Ctrl](https://woodwerd.github.io/tool-ctrl/) shows for review.

- **Use it:** [woodwerd.github.io/photo-ctrl](https://woodwerd.github.io/photo-ctrl/)
- **The skill:** the [`skill`](skill/) folder. Put it in `~/.claude/skills/woodwerd-photo` and use it from Claude Code.

Photo Ctrl runs in your browser. Photos are shrunk to 2,048 px and have their location and camera details removed on your device, then go only to the private repo you connect. Nothing is sent to WOODWERD.
